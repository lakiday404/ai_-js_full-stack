## 一、文档流基础

### 什么是文档流？

**文档流**（Normal Flow）是页面布局的默认排列方式，元素从上往下、从左往右依次排列，呈现一种**流式**的排列效果。

> 一个 HTML 就是一个文档，文档中的元素默认按照文档流的方式进行布局。

```
┌─────────────────────────────────────┐
│  块级元素 1（独占一行）              │
├─────────────────────────────────────┤
│  块级元素 2（独占一行）              │
├──────────┬──────────────────────────┤
│ 行内元素  │  行内元素（并排显示）    │
├──────────┴──────────────────────────┤
│  块级元素 3（独占一行）              │
└─────────────────────────────────────┘
```

### 文档流的特性

1. **从上往下**：块级元素依次垂直排列
2. **从左往右**：行内元素水平排列，宽度不够自动换行
3. **自动填充**：块级元素默认占满父容器宽度

## 二、三种元素类型详解

根据 `display` 属性的不同，元素分为三大类：

### 1. 块级元素（Block）

| 特性 | 说明 |
|------|------|
| 独占一行 | 默认占据父容器一整行 |
| 可设宽高 | `width`、`height` 属性有效 |
| 典型代表 | `div`、`p`、`h1~h6`、`ul`、`li` |
| display 值 | `block`（默认） |

```html
<style>
  .block {
    width: 200px;
    height: 100px;
    background: red;
  }
</style>
<div class="block">我是块级元素</div>
```

### 2. 行内块级元素（Inline-Block）

| 特性 | 说明 |
|------|------|
| 可同行排列 | 像行内元素一样水平排列 |
| 可设宽高 | 像块级元素一样设置尺寸 |
| 典型代表 | `img`、`button`、`input` |
| display 值 | `inline-block` |

```html
<style>
  .inline-block {
    width: 100px;
    height: 100px;
    background: green;
    display: inline-block;
  }
</style>
<div class="inline-block"></div>
<div class="inline-block"></div>
<!-- 两个盒子可以在同一行并排显示 -->
```

### 3. 行内元素（Inline）

| 特性 | 说明 |
|------|------|
| 可同行排列 | 水平方向依次排列 |
| **不可设宽高** | `width`、`height` 属性无效 |
| 宽高由内容决定 | 由内部文本或子元素撑开 |
| 典型代表 | `a`、`span`、`strong`、`em` |
| display 值 | `inline`（默认） |

```html
<style>
  a {
    width: 100px;  /* ❌ 无效，行内元素不能设置宽高 */
  }
</style>
<a href="#">链接文本</a>
<span>行内文本</span>
```

### 三种元素对比

| 类型 | 同行排列 | 设置宽高 | 默认行为 |
|------|---------|---------|---------|
| `block` | ❌ 独占一行 | ✅ 可以 | 占满父容器宽度 |
| `inline-block` | ✅ 可以 | ✅ 可以 | 按内容宽度排列 |
| `inline` | ✅ 可以 | ❌ 不可以 | 按内容宽度排列 |

## 三、定位属性详解

CSS 提供了四种定位方式，通过 `position` 属性控制。

### 1️⃣ 相对定位 relative

#### 定义

**相对定位**是相对于元素**自身在文档流中的原始位置**进行偏移。

#### 核心要点

| 要点 | 说明 |
|------|------|
| 参考对象 | **自己本身**在文档流中的位置 |
| 是否脱离文档流 | ❌ **不脱离**，原始位置依然被保留 |
| 触发方式 | `position: relative` |

#### 代码示例

```html
<style>
  .box {
    width: 100px;
    height: 100px;
    background: rebeccapurple;
    position: relative;
    left: 100px;  /* 相对于原始位置向右偏移 100px */
    top: 50px;    /* 相对于原始位置向下偏移 50px */
  }
</style>
<div class="box"></div>
```

#### 偏移效果示意

```
原始位置：
┌──────────────────────────────────┐
│                                  │
│    ┌──────────┐                  │
│    │  原始位置  │                  │
│    └──────────┘                  │
│                                  │
└──────────────────────────────────┘

相对定位后（left: 100px; top: 50px）：
┌──────────────────────────────────┐
│          ┌──────────┐            │
│          │  偏移后   │  ← 向右100px │
│          │           │            │
│          └──────────┘  ← 向下50px  │
│    ┌──────────┐（原始位置空位保留）  │
└──────────────────────────────────┘
```

**重要**：原始位置的**占位空间依然保留**，后续元素不会顶上来！

---

### 2️⃣ 绝对定位 absolute

#### 定义

**绝对定位**是相对于最近的**拥有定位属性的父级元素**进行定位。

#### 核心要点

| 要点 | 说明 |
|------|------|
| 参考对象 | 最近的**有定位属性**的祖先元素 |
| 是否脱离文档流 | ✅ **完全脱离**，原始位置不复存在 |
| 如果找不到参考 | 最终会以 `body` 为参考标准 |

#### 什么是"有定位属性"？

只要设置了以下任意一种 `position` 值，就算有定位属性：
- `position: relative`
- `position: absolute`
- `position: fixed`
- `position: sticky`

#### 代码示例

```html
<style>
  .box {
    width: 300px;
    height: 300px;
    border: 1px solid #000;
    position: relative;  /* 父容器设置相对定位作为参考 */
  }
  .wrap {
    width: 50px;
    height: 50px;
    background: #ee13c2;
    position: absolute;  /* 子元素绝对定位 */
    left: 125px;
    top: 125px;         /* 相对父容器 .box 偏移 */
  }
</style>
<div class="box">
  <div class="wrap">hello</div>
</div>
```

#### 绝对定位的"找爸爸"机制

```
情况1：父容器有定位属性
┌──────────────────────────────────┐
│ .parent (position: relative)     │  ← 参考对象
│  ┌──────────┐                    │
│  │  child   │ ← 相对父容器定位    │
│  │ absolute │                    │
│  └──────────┘                    │
└──────────────────────────────────┘

情况2：一直找到 body
html
 └── body  ← 最终参考对象
      └── div (无定位)
           └── span (无定位)
                └── .child (absolute)
                如果所有祖先都没有定位属性，则以 body 为参考
```

#### 脱离文档流的影响

```html
<!-- 对比演示 -->
<style>
  .box { position: relative; }
  .wrap {
    position: absolute;  /* 脱离文档流 */
    /* 不占空间，.name 会顶上来 */
  }
  .name { /* 正常文档流 */ }
</style>
<div class="box">
  <div class="wrap">hello</div>   <!-- 脱离文档流 -->
  <div class="name">帆帆</div>    <!-- 占据原本 .wrap 的位置 -->
</div>
```

**脱离文档流后**：
- 就好像这个元素从页面中**漂浮**起来
- 不再占据任何空间
- 后续元素会填补它的位置

#### 🎯 实战技巧：子元素居中

利用绝对定位 + transform 实现完美居中：

```css
.child {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

```
┌──────────────────────────┐
│     父容器               │
│                          │
│        ┌──────┐          │
│        │ 居中  │          │
│        └──────┘          │
│                          │
└──────────────────────────┘
```

**原理说明**：
| 属性 | 百分比参考对象 |
|------|---------------|
| `left: 50%` | **父容器**的宽度 |
| `top: 50%` | **父容器**的高度 |
| `translate(-50%, -50%)` | **自身**的宽高 |

`translate` 的百分比是以**自身宽高**为参考，所以 `-50%` 就是向左、向上移动自身的一半，从而实现完美居中。

### 3️⃣ 固定定位 fixed

#### 定义

**固定定位**是相对于**浏览器可视区域**进行定位，**不随页面滚动而移动**。

#### 核心要点

| 要点 | 说明 |
|------|------|
| 参考对象 | **浏览器可视窗口**（viewport） |
| 是否脱离文档流 | ✅ **完全脱离** |
| 滚动行为 | **固定不动**，始终在屏幕相同位置 |

#### 代码示例

```html
<style>
  body {
    height: 2000px;  /* 制造滚动效果 */
  }
  .box {
    width: 100px;
    height: 100px;
    background: red;
    position: fixed;
    bottom: 10px;   /* 距离底部 10px */
    right: 10px;    /* 距离右侧 10px */
  }
</style>
<body>
  <div class="box"></div>
  <!-- 滚动页面时，红色方块始终固定在右下角 -->
</body>
```

#### 典型应用场景

| 场景 | 示例 |
|------|------|
| 回到顶部按钮 | 页面滚动时始终显示 |
| 悬浮导航栏 | 固定在页面顶部 |
| 在线客服 | 固定在右下角 |
| 广告弹窗 | 始终在屏幕中央 |

```
滚动前：                   滚动后：
┌──────────────────┐      ┌──────────────────┐
│  ┌────────────┐  │      │   内容滚动上去了    │
│  │   navbar ↑  │  │      │                  │
│  └────────────┘  │      │                  │
│                  │      │                  │
│    内容区域       │      │    内容区域        │
│                  │      │                  │
│         ┌──┐     │      │         ┌──┐     │
│         │回│     │      │         │回│     │
│         │顶│     │      │         │顶│     │
│         └──┘     │      │         └──┘     │
└──────────────────┘      └──────────────────┘
  navbar 和 回到顶部按钮     navbar 和 回到顶部按钮
  始终固定在视口位置         始终固定在视口位置
```

---

### 4️⃣ 粘性定位 sticky

#### 定义

**粘性定位**是 `relative` 和 `fixed` 的结合体，在**到达指定位置前是相对定位**，到达后变为**固定定位**。

#### 核心要点

| 要点 | 说明 |
|------|------|
| 参考对象 | **浏览器可视区域** |
| 是否脱离文档流 | ❌ **不脱离** |
| 行为特点 | 滚动到阈值前相对定位，到达阈值后固定 |

#### 代码示例

```html
<style>
  body {
    height: 300vh;  /* 3倍可视高度，制造滚动 */
  }
  .box2 {
    height: 100px;
    background: blue;
    position: sticky;
    top: 0;        /* 阈值：滚动到顶部时固定 */
  }
</style>
```

#### 滚动行为演示

```
初始状态（未滚动）：
┌──────────────────┐
│  普通内容         │
├──────────────────┤
│  .box2 在文档流中  │  ← 表现为相对定位
├──────────────────┤
│  更多内容         │
└──────────────────┘

滚动到 top: 0 位置时：
┌──────────────────┐
│  .box2 固定在顶部  │  ← 变为固定定位效果
├──────────────────┤
│                  │
│  内容继续滚动     │
│                  │
└──────────────────┘

继续滚动：
┌──────────────────┐
│  .box2 固定在顶部  │  ← 一直固定
├──────────────────┤
│                  │
│  内容继续滚动     │
│                  │
└──────────────────┘
```

#### 典型应用：表头固定

```css
/* 表格滚动时，表头始终可见 */
th {
  position: sticky;
  top: 0;
  background: white;  /* 必须设置背景，否则内容会透过去 */
}
```

## 四、层级控制 z-index

### 基本概念

`z-index` 控制元素的**叠放顺序**，值越大越靠上。

| 要点 | 说明 |
|------|------|
| 生效条件 | **必须配合定位属性**（relative/absolute/fixed/sticky） |
| 默认值 | `auto`（按照文档流顺序排列） |
| 比较范围 | **只能在兄弟元素之间比较** |

### 代码示例

```html
<style>
  .box {
    position: absolute;
    z-index: 1;  /* 层级为 1 */
  }
  .box2 {
    position: sticky;
    top: 0;
    /* z-index 默认 auto，比 1 小 */
  }
</style>
```

### 层级比较规则

```
后设置的层级 > 先设置的层级

┌────────────────────────────────────┐
│                                    │
│  ┌─ .box (z-index: 2) ──┐         │
│  │    ☝ 显示在最上面     │         │
│  └──────────────────────┘         │
│                                    │
│  ┌─ .box2 (z-index: 1) ─┐        │
│  │    ☝ 在中间            │        │
│  └──────────────────────┘         │
│                                    │
│  ┌─ .box3 (无定位) ────┐          │
│  │    ☝ 在最下面         │          │
│  └──────────────────────┘          │
│                                    │
└────────────────────────────────────┘
```

### 注意事项

1. **必须有定位**：`z-index` 只有在元素设置了 `position` 属性时才生效
2. **兄弟比较**：不同父容器下的子元素，层级比较以父容器的 `z-index` 为准
3. **默认顺序**：不设置 `z-index` 时，**后面的元素覆盖前面的元素**

```html
<!-- 错误认知 ❌ -->
<div class="parent1" style="z-index: 1">
  <div class="child" style="z-index: 999"></div>
</div>
<div class="parent2" style="z-index: 2">
  <div class="child" style="z-index: 1"></div>
</div>
<!-- parent2 的 z-index 更大，所以它的子元素显示在上面 -->
```

## 五、定位实战技巧

### 技巧1：元素水平垂直居中

```css
.center {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

| 属性 | 百分比参考对象 |
|------|--------------|
| `left: 50%` | **父容器宽度** |
| `top: 50%` | **父容器高度** |
| `translate(-50%, -50%)` | **自身宽高的 50%** |

### 技巧2：固定定位模拟遮罩层

```css
.mask {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  background: rgba(0, 0, 0, 0.5);
  z-index: 999;
}
```

### 技巧3：粘性定位实现吸顶导航

```css
.nav {
  position: sticky;
  top: 0;
  z-index: 100;
  background: white;
}
```

### 技巧4：相对定位微调元素位置

```css
.icon {
  position: relative;
  top: -2px;  /* 向上微调 2px，对齐文字 */
}
```

## 六、总结对比

### 四种定位方式速查表

| 定位类型 | 属性值 | 参考对象 | 脱离文档流 | 滚动行为 |
|---------|--------|---------|-----------|---------|
| **静态定位** | `static`（默认） | 文档流 | ❌ | 随页面滚动 |
| **相对定位** | `relative` | **自身原始位置** | ❌（占位保留） | 随页面滚动 |
| **绝对定位** | `absolute` | **最近的有定位的父元素** | ✅ | 随父元素滚动 |
| **固定定位** | `fixed` | **浏览器视口** | ✅ | **固定不动** |
| **粘性定位** | `sticky` | **浏览器视口** | ❌ | 到达阈值后固定 |

### 判断流程图

```
需要控制元素位置？
    │
    ├── 需要脱离文档流？
    │   ├── ✅ 是 → 需要相对于谁定位？
    │   │   ├── 浏览器视口 → fixed
    │   │   └── 父元素/body → absolute
    │   │
    │   └── ❌ 否 → 需要什么行为？
    │       ├── 微调自身位置 → relative
    │       └── 滚动到阈值后固定 → sticky
    │
    └── 不需要控制位置 → static（默认）
```

### 元素类型速查表

| 类型 | display | 同行排列 | 设置宽高 | 常见元素 |
|------|---------|---------|---------|---------|
| 块级 | `block` | ❌ | ✅ | `div`, `p`, `h1` |
| 行内块级 | `inline-block` | ✅ | ✅ | `img`, `button` |
| 行内 | `inline` | ✅ | ❌ | `a`, `span` |

### z-index 层级速查

| 要点 | 说明 |
|------|------|
| 生效条件 | 必须配合 `position` 属性 |
| 比较规则 | **兄弟元素之间**比较 |
| 值越大 | 显示层级越高（越靠上） |
| 后设置优先 | 兄弟元素中后设置 `z-index` 的优先 |

---

## 📌 总结

CSS 定位布局的核心在于理解**参考对象**和**文档流**两个概念：

1. **文档流**是页面布局的基石，理解它才能理解定位的"脱离"含义
2. **定位的核心**是明确"相对谁偏移"
3. `relative` 保留下水（不脱离文档流），`absolute/fixed` 切断后路（脱离文档流）
4. `sticky` 是前两者的结合体，适合吸顶、表头固定等场景
5. `z-index` 一定要配合定位使用，且只能在兄弟元素间比较

掌握了这些，你就能自如地控制页面上任何一个元素的位置了！
