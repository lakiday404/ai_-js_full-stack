# 浮动布局

## 文档流
浏览器渲染页面时，遵守从上到下、从左到右的顺序 **流式排布**，这种页面的排版方式就是文档流

img 是行内元素，但是因为是媒体标签，媒体标签可以设置宽高

## 浮动布局
- 文字环绕
1. float: left; 浮动会导致元素脱离文档流，但是一定不会覆盖文字
2. 浮动元素的层级默认是最高的
3. 浮动元素会导致父容器高度塌陷，进而影响后续的容器排版
> float 浮动只能左右浮动，top、bottom设置不了
> 块级元素变成行内块级元素的时候，因为换行字符也会带来一点间距，所以会又兼具

### 清除浮动带来的负面影响
1. 直接给父容器设置足够高的高度，但是不推荐，很难设置的贴切需求,缩放的时候容易报废
2. 在浮动元素的末尾增加一个空容器，设置 `clear: left;` 当然，也可能是右边浮动，直接写 `clear:both;` 就可以了 
3. 为父容器设置 `after` 伪元素，在伪元素上 `clear:both;`  推荐这样写
4. 被影响的元素设置 `clear:both;` 不推荐这样写
5. 把父容器设置成 BFC 容器，这个方法不是为了清除`float`而来的，但是可以刚好消除float的影响

### BFC (block formatting context) 块级格式化上下文


**margin重叠问题**：
1. 父子容器的`margin-top`天生会重叠
- BFC 的核心渲染规则:
1. BFC 内部的子元素也是 从上往下、从左往右排列
2. BFC 容器是一个独立的拥有特殊渲染规则的容器，它内部的子元素不会影响外部
3. **BFC 容器在计算高度的时候，会将浮动的子元素的高度也计算在内** 

因为父子容器的`margin-top`会重叠，设计了 BFC 来解决这个问题，让需要被解决的容器变成 BFC 容器
> 超出父容器的部分都隐藏，将一个容器变成 BFC 容器，改变了渲染机制

**如何创建BFC容器** :
1. overflow:hidden || auto || overlay || scroll;
2. position: absolute || fixed;
3. float: left || right || both;
4. display: flex || grid || inline-xxxx;
