# 语言

* 前端 - 要能跟界面产生交互 (Web端、桌面应用)
- js 能做任何前端
- js 早期只能做前端

* 后端 - 要跟操作系统交互
- 有 `node` 之后就可以进行读写操作了


* 为什么编程语言要区分为 前端、后端
- 因为综合在一起会过于臃肿复杂
- `AIGC`全栈工程师，不再需要纯前端

- `token` - 词元，ai的燃料，有点类似于流量 
- `CPU` 和系统交互

## node.JS
- js 运行环境
- 用 c 和 c++ 写的，封装了很多可以跟 OS 交互的模块，这些模块可以被 js 灵活的使用
- 对比 java 写后端的优势：天生支持高并发
