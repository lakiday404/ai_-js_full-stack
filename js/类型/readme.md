# V8执行的过程
1. 创建一个 **调用栈** （来存放预编译的过程）
2. 在调用栈中，存入 xx 执行上下文（GO、AO）
3. 执行代码，将 原始值 存入 栈中，如果遇到引用类型的值，则将值存入堆空间并生成一个引用地址（指针），将引用地址存入栈中。
这样设计的好处：既保证了栈不用设计的很大，从而影响V8的执行效率；又不会爆栈
