## 拷贝 `copy`

概念 ：克隆一份 原对象，得到一份 新对象

- 浅拷贝
将原对象中的 属性全部拷贝，遇到引用类型时则保留其引用地址
> `Object.assign({},obj)` 是拷贝，但只是 浅拷贝。原始类型的值拷贝了，但引用类型只拷贝其地址
数组调用slice也可以浅拷贝 `[].slice(0)`
<!-- 其他浅拷贝的方式，是否有两个数组合并的方式 -->

- 深拷贝
将原对象中的所有子对象，层层拷贝，引用地址都是全新的
