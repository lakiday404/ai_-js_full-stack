#  js作用域链
- 每一个执行上下文的变量环境中都存在一个 outer 指针，用来指向外部的执行上下文。
- 当 V8 在查找一个变量时，在当前执行上下文中没有找到，就会顺着 outer 所指向的那个执行上下文查找，以此类推。直到找到全局为止。
- 我们把这个查找的链条称为作用域链。

* 词法作用域：这个函数声明在哪，这个函数词法作用域就在哪。词法环境这个空间也是一个栈

# 闭包
1. 一个函数执行完毕后，它的执行上下文会被销毁
舞台的例子，你方唱罢，我方登场
2. 根据作用域的查找规则，内部函数一定可以访问外部函数中的变量
当一个外部函数中的内部函数被拿到外部函数之外来执行，哪怕外部外部函数执行完毕了，被内部函数引用的那部分变量依然需要保留，我们把这部分变量的集合称之为闭包
<!-- 闭包 = 函数 + 它引用的外部变量的集合 -->
非必要不写闭包。

- 缺点：内存泄露
- 优点：定义私有模块，防止全局变量污染

内层函数需要访问外层函数的某个变量，而外层函数执行完了会销毁掉其词法作用域。为了避免这种情况，销毁的时候会保留下一个闭包 closure
