# JS的执行
1. v8会读取JS代码，不会立刻执行，先编译
2. 分词：即词法分析。把代码拆分开为一个个**词法单元**
3. 解析：即语法分析。将词法单元组织成一个 **语法树** AST（抽象语法树）
4. 执行：根据 AST 生成代码并执行

# JS声明提升
因为JS编译的时候是拆开再重组，所以会导致JS里先输出一个未定义的变量，再在下文定义这个变量，不会报错
如果直接输出一个从来没被定义的变量，才会报错

1. 全局作用域   //被执行的那一刻，最外层的作用域，即整份代码
2. 函数作用域
//只有这两种作用域（其实不是）。for循环语句里面不存在所谓的作用域，只有全局作用域。

# let，const
let
<!-- let是后来增加的，修复了不出bug的bug，例如不能重复声明、不能声明变量之前使用这个变量
let声明的变量，是块级作用域的，只能在块级作用域内使用，不能在块级作用域外使用(局部变量) -->
1. let + {} = 块级作用域，哪怕就写个光秃秃的{}也成立
2. let 不会带来声明提升
1的结论，如：
```
{
    let a=10
}
console.log(a)
会报错，无法输出
```

const
1. const是常量，不能重新赋值，也不能重新声明
例如
let a=10
a=20
不会报错，可以重新赋值

const a=10
const a=12
则会报错，不可以赋值了
