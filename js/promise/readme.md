## 异步、同步
### 同步
1. 在同一时间线上，一步接一步
### 异步
1. 能按顺序从上往下一次执行
2. 在执行的过程中，如果碰到一个耗时的任务，就分出精力来执行另一个任务 (**异步执行**)
- 可以类比于并联和串联（此处应插图）
- 也可以类比小学题，洗衣服的同时扫地；烧水的时候晒衣服。

** `js`是默认单线程执行的**
1. **线程**: cpu 执行指令所需要的时间。本质是时间单位
2. **进程**: cpu 接到一个指令，等待上下文加载完毕所需要等待的时间。本质也是时间单位
3. 进程比线程要大，也可以说线程是进程的一部分
// 清后台的时候关掉的进程 这个进程不是同个进程
> 在浏览器上打开一个 `tab` 网页，称之为开启一个新的进程。这个进程中，网页需要加载数据、渲染页面等等，这些通力合作得到一个进程的任务叫线程
> 例如 HTTP 网络线程、页面渲染线程

* 用 node 来运行  js ，这可以称之为一个进程，但是 v8 **默认**只会开启一个线程来执行代码。
> 在某些特殊情况下，v8 可以开启多线程
* v8 碰到一个耗时的任务，会将其挂起，然后先去执行不耗时的任务，最后找已经挂起的地方执行
<!-- 如果改成多线程，由于在网页上运行，容易导致线程冲突 -->

### 回调
- 当 B 函数需要依赖异步函数 A 的结果，我们将 B 函数的调用放在 A 里面
- 缺点:可维护性差，引起 回调地狱
**回调地狱**: 当程序繁重，排查问题的难度大，可读性差。容易引起大规模崩盘
