# 对象
- 在js中，万物皆对象
<!-- - V8 只要看见 {} 就会直接 new 一个对象 -->
<!--本质上 js 创建对象只有一种方式，那就是 new Object() -->

1. 原始类型：string boolean undefined bigint null symbol
2. 引用类型：object array function

* 完全一致属性的两个对象，但他们并不相等
* 引用类型比较是否相等，首先看引用地址是否相等
* js中没有完全一样的两个对象，因为其引用地址不可能重复


## 创建对象的方式
1. 字面量
2. new Object()
3. new 一个构造函数
<!-- new 一次构造函数就得到一个实例对象 -->
<!-- - 被 new 调用的函数就叫做构造函数 -->
- 函数有二义性： 可以普通调用，也可以 new 调用，并且会得到一个新对象

- new 的工作原理：
1. new 会往函数内凭空创建一个 this 对象
2. 执行函数中的代码
3. 让隐式原型（这个对象的原型） 等于 显式原型（函数的原型）
<!-- this.__proto__ = 对象.prototype -->
4. return 这个对象
<!-- return this -->

## 包装类
- 原始类型是不能添加属性和方法的
- V8在对象中查找属性，如果找不到，一定会去它的原型上找

1. 当用户创建一个字面量，V8会默认之形成 new Xxxfunction（）
2. 因为原始类型不能增加属性和方法，所以，V8在new出这个实例对象后，立即会做一个**拆箱**操作（把刚加进去的属性移除掉）
3. str.length  length是 String 函数原型上的属性，并不是给字符串增加的属性




## js 原型
1. 函数的显式原型 prototype
2. 对象的隐式原型 __proto__


### 原型查找链机制
任何对象最终都继承自 Object.prototype(原型为 null)
- V8找不到某个值，就会顺着原型链查找
 Person.prototype  ←───  p.__proto__
      │                      │
      │                      │
      ▼                      ▼
  { constructor: Person }  → 指向同一个对象
