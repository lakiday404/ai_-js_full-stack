# `this` 
## 为什么要有 `this`
- `this`是 js 中的一个关键字，它提供了一种更优雅的方式，**隐式地传递一个**对象的引用，可以让代码更高效、更简洁，易于复用。

## `this`用在哪
- 有域的地方就可以用
1. 全局    `this === window` 
> `this`在`Node`中直接输出，是个空对象；在网页中输出，则代表整个`window`
2. 函数体内
(块级作用域内`this`无意义，因为ES6才出现的块级作用域，而`this`定义在其之前)

> `this`用在不同的地方，代指的内容是不一样的
## `this`的绑定规则
<!-- 此内容源自 《你不知道的JavaScript》 -->
1. 默认绑定
- 当函数**独立调用**时，函数中的 `this`指向`window`对象，undefined
2. 隐式绑定规则
- 当一个函数被一个上下文对象所拥有，并被该对象调用，函数中的`this`指向该对象
3. 隐式丢失（隐式绑定）
- 当一个函数被多层对象调用，函数的 `this`指向最近的那个对象
4. 显式绑定
**显式绑定有三种类型**：
- `fn.call(obj)` 可以把前一个函数的强行掰弯到`obj`中去
<!-- call的源代码会触发fn()  -->
- `fn.apply(obj,[x,y])`
- 和`call`大部分一样，但`apply`接受参数方式不一样，要用数组传递


- `var bar = fn.bind(obj,x,y)`
- `bar()`

5. `new` 绑定
- `new` 的原理会导致函数的 `this`指向实例对象`obj`

## 箭头函数
- 箭头函数没有`this`这个概念
- 写在箭头函数内的 `this`是其外部非箭头函数的`this`
- 箭头函数不能作为构造函数来使用，new的执行步骤中用到了把this指向其prototype
