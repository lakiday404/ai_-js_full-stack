# 函数体内的预编译
1. V8引擎遇到函数声明时，创建一个执行上下文（对象） AO：{}
2. 找形参和变量声明，将形参和变量名作为属性名，添加到 AO 中，值为 undefined
3. 将形参和实参统一
4. 在函数体内找函数声明，将函数名作为 AO 的属性名，函数体作为属性值，添加到 AO 中
//  老板和秘书的关系。V8引擎拿到代码让编译器先预编译，老板行程由秘书安排
//  对象中不会存在两个相同的属性名，如果有，后定义的会覆盖前定义的
// 函数可以不取名字，即匿名函数

# 全局的预编译
1. 创建一个全局的执行上下文（对象） GO：{}
2. 找全局变量声明，将全局变量名作为属性名，添加到 GO 中，值为 undefined
3. 找全局函数声明，将函数名作为GO的属性名，函数体作为属性值

4. 执行全局代码，有函数体再进行函数体内的预编译。
